# What must wait for the producer (SC-125470) and gateway (SC-125471) PRs

Producer: https://app.shortcut.com/preset/story/125470. Gateway:
https://app.shortcut.com/preset/story/125471. Qualification:
https://app.shortcut.com/preset/story/125472.

This phase deliberately did not depend on either. These items cannot be completed or
trusted until their code exists; each lists what to re-run and what in this repo to replace.

## Needs the producer PR (SC-125470)

| Item | Why it waits | What to do when it lands |
|---|---|---|
| The named-tool contract as shipped (names, annotations, schema compaction) | The baseline catalog is Superset master from 2026-10-08, which already lists 79 named tools; the producer story may change names, annotations and descriptions | Re-capture with `capture/capture_superset_catalog.py` against the PR build; re-run `python -m testmcpy.qualification run`; diff `results.json` |
| The legacy discovery compatibility mode | The generic surface here is today's `search_tools`/`call_tool`; the new explicit compatibility flag and its listing behaviour are unknown | Add it as a fourth surface in `server.py`/`runner.py`; keep the 12 tasks |
| Slimmer definitions (B02 currently fails: median 519 vs 400, p95 1,556 vs 1,200) | Only the producer can shrink descriptions/schemas | Re-measure B01/B02; the heaviest are `manage_native_filters`, `generate_chart`, `list_datasets`, `list_charts` |
| Annotation values per tool, notably `execute_sql` | B09 and the client approval behaviour depend on them | Re-run B09; decide with the owner whether SQL counts as read |
| Knowledge tools and the "Knowledge disabled" behaviour | No Knowledge tool exists in the captured catalog; the two fixture tools and the `FEATURE_DISABLED` code are assumptions | Replace `KNOWLEDGE_TOOLS` and the error code in `world.py` with the real contract |
| Typed errors (`PERMISSION_DENIED`, old-producer, revoked) as the producer emits them | The fixture codes are invented stable names | Align `FixtureError` codes and re-check B12 on the real app |
| Real isolation (roles, RLS, workspace) | B11 was measured on the fixture only | Port the probe matrix to the real app with seeded users; run in staging |
| Dispatcher fidelity after any change to `call_tool` | The unknown-tool attribution gap (8 of 9 probes identical) is in the current dispatcher | Re-run `capture/probe_superset_fidelity.py` |
| Tool-list pagination on the producer | Today it returns one page of 79 | Re-run pagination probes against the real list |

## Needs the gateway PR (SC-125471)

| Item | Why it waits | What to do when it lands |
|---|---|---|
| Native multi-workspace tool shape | The fixture assumes a required `workspace_id` property on every named tool (`_native_gateway_tools`); the real shape may differ (per-workspace namespaces, a selector tool, ...) | Replace `_native_gateway_tools` and the runner's gateway wiring; re-run `workspace-switch`, `old-producer-unsupported`, `revoked-access` |
| Gateway annotations | `fixtures/gateway-generic-tools.json` marks `call_tool` as broadly destructive and the others read-only by assumption (the hints are not visible to a client's tool list) | Capture real values; re-run B09 |
| Tool-list size across workspaces | Whether the gateway lists the union of workspaces' tools or one workspace's tools changes B01 | Re-measure B01/B03 on the gateway list |
| Old-producer behaviour through the gateway | `UNSUPPORTED_PRODUCER` and its compatibility hint are fixture inventions | Align code and message; re-check B07/B12 |
| Grant revocation propagation and connection reuse | Revoked-access is modelled as an immediate typed error; real propagation delay and cache behaviour are unknown | Staging test with a real revoke; record time to effect |
